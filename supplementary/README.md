# Supplementary results

The results that the paper summarizes but does not report in full. Every number is computed from the runs in `results/` by `analysis/supplementary.py`; the LaTeX version of every table is in `tables/`, the figures of the whole grid in `figures/`. Models: Equiv (equivariant circuit, invariant observable), Twirled (NonEquiv-Twirled), NonEquiv, NoSym (Equiv-NoSym). Accuracies are fractions; the generalization gap is the training minus the test accuracy.
